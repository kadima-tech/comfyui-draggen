# Draggen Remote Loader

Fetches a moodboard from Draggen.io. A Draggen subscription and API key are required.

## Inputs

- **moodboard_id**: Board id from the Draggen URL. **Load Boards** lists your boards after the API key is set and fills this in.
- **api_key**: Key from the account tab at https://draggen.io/dashboard.

## Output

- **moodboard**: The loaded board. Connect it to Draggen Board to Image, Draggen Extract Images, or Draggen Extract Text.
