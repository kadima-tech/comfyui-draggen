# Draggen Local Loader

Loads a moodboard exported from [Draggen](https://draggen.io) on this machine. No API key is required.

## Inputs

- **folder_path**: Absolute path to the export folder. The folder needs the moodboard JSON (`data.json`) and an `images` subfolder.

## Output

- **moodboard**: The loaded board. Connect it to Draggen Board to Image, Draggen Extract Images, or Draggen Extract Text.
