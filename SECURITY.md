# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately. Do not open a public GitHub issue.

Use GitHub private vulnerability reporting:

1. Open [Security advisories](https://github.com/kadima-tech/ComfyUI-Draggen/security/advisories) for this repository.
2. Choose **Report a vulnerability**.
3. Include what is affected, how to reproduce it, and the impact if you know it.

We will acknowledge the report, investigate, and coordinate a fix and disclosure through a GitHub security advisory.
